# Mimi Pastry

A responsive, multi-page bakery website for Mimi Pastry, Kaduna, Nigeria.

## Pages
- Home — brand introduction, celebration highlights and custom-order calls to action
- Wedding & Birthday Cakes — cake collection, quote links and ordering process
- Pastries & Drinks — meat pie, fish roll, egg roll, chin chin and zobo
- Our Story — brand story and values
- Contact & Orders — contact details and a WhatsApp enquiry form

## Brand details
- Slogan: “Freshly bake, with love”
- Palette: warm cream, chocolate brown and burnt orange
- Orders: WhatsApp enquiries and personalised quotes; no public prices
- Phone / WhatsApp: +234 902 564 4471
- Email: goodnessbeauty@gmail.com
- Location: Kaduna, Nigeria

## Run locally
Open `index.html` in a browser, or serve the folder with a local static server.

## Before launch
- Replace temporary Unsplash bakery photography with approved Mimi Pastry product photos.
- Add the Miracode portfolio URL to the footer credit in `assets/js/app.js`.
- Verify phone, WhatsApp, email and location with the business owner.
- Test the website on current desktop and mobile browsers.

The logo is a round chocolate-and-gold badge featuring a woman baker. The site uses plain HTML, CSS and JavaScript and is suitable for static hosting such as GitHub Pages or Cloudflare Pages.
